# Project status

## Falling dice

The maintained dice project is a custom dense rigid-body research implementation and CPU renderer. It preserves the latest 1,000-die, no-pile-creep scene source and validation tooling. It is not a replacement for a commercial TGS/GJK/EPA solver.

## Metamaterial compression

The maintained compression project uses six mechanical degrees of freedom per node, geometrically nonlinear beam kinematics, elastoplastic internal variables, self-contact, rigid platen contact, quasi-static equilibrium, load/unload accounting, numerical verification, a CPU path tracer, and implicit-union STL generation.

The default printed-polymer card is provisional. Quantitative force, energy absorption, and permanent-set predictions require calibration against printed coupons, anisotropy, viscoelasticity, fracture, rate, temperature, and platen-friction data.
